# JavaScript 계산기

## 📋 구현할 기능 목록

### 1. 기본 계산 기능
- [ ] 두 개의 숫자에 대한 덧셈
- [ ] 두 개의 숫자에 대한 뺄셈  
- [ ] 두 개의 숫자에 대한 곱셈
- [ ] 두 개의 숫자에 대한 나눗셈

### 2. 입력 검증 기능
- [ ] 숫자가 아닌 값 입력 시 예외 처리
- [ ] 0으로 나누기 시 예외 처리
- [ ] 빈 값 입력 시 예외 처리

### 3. 사용자 인터페이스
- [ ] 계산기 화면 출력
- [ ] 사용자 입력 받기
- [ ] 계산 결과 출력
- [ ] 프로그램 종료 기능

### 4. 추가 기능
- [ ] 계산 이력 저장 및 출력
- [ ] 계산 이력 초기화 기능

## 🚀 실행 방법

```bash
npm start
```
